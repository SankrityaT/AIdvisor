# Compass — Project Spec
**ASU AIR Spark Challenge · Submission due tonight, 11:59 PM**

---

## 1. One-line pitch

An AI academic advisor that builds a student a personalized route to graduation, then reroutes it live the moment reality gets in the way (a class fills up, gets cancelled, whatever) — instead of the student finding out three weeks later in an advisor's inbox.

## 2. Core user flow

1. **Quiz** — student answers a few questions: intended major, career goal, risk tolerance (easy classes vs. rigorous), priority (learn deeply vs. protect GPA).
2. **Flowchart generation** — AI cross-references the major map + course sentiment data against quiz answers, generates a full semester-by-semester plan to graduation.
3. **Flowchart renders** — visual route map, semesters as stations, courses as stops along the line.
4. **Disruption** — a "Simulate Registration" button jumps to semester 3. Two planned classes come back unavailable (one full, one not offered). This is scripted/deterministic, not random.
5. **AI reroutes** — explains what broke, finds a valid substitution or reordering that preserves prereqs and the graduation date, regenerates the flowchart live, shows old → new diff.
6. **Voice** — student can ask Compass questions by voice at any point; Compass can answer by voice too.

## 5. Disruption scenario (hardcode this exact scenario for the demo)

- **Trigger**: student clicks "Simulate Registration" while on Semester 3.
- **What breaks**: `CSE355` returns `status: "full"`, `CSE240` returns `status: "not_offered"`.
- **Reroute logic**: AI reasoner agent receives the break event + the major map + prereq graph, outputs a valid substitution (e.g. move CSE355 to Semester 4, swap CSE240 for an equivalent like CSE230) that satisfies all downstream prereqs and does not push the graduation semester back.
- **UI response**: old plan struck through, new plan highlighted, one-sentence explanation surfaced in chat.

|---|---|---|
| `lead` | `qwen38-27b` | Primary builder, delegates, calls critic before finishing |

| `reasoner` | `qwen3-235b-a22b-thinking-2507` | Heavy multi-step reasoning — reroute logic, disruption handling |

Voice: `qwen3-asr-1p7b` (speech-to-text), `qwen3-tts-customvoice-1p7b` or `chatterbox` (text-to-speech), called directly via the same `openai.rc.asu.edu/v1` gateway.

- Single-page web app, no framework requirement, plain HTML/CSS/JS is fine and fastest to demo (no build step)
- No database — everything runs off the static JSON files + in-memory state
- No auth — one hardcoded demo persona
- No external map APIs, no live scraping, no third-party voice APIs

## 10. Demo script (90 seconds, lead with this)

1. Open on the quiz, answer in 10 seconds.
2. Flowchart renders — "here's my route to graduation."
3. Hit Simulate Registration live on stage.
4. Alert fires — two classes just broke.
5. Reroute appears in real time — old plan struck through, new plan in teal, graduation date unchanged.
6. Ask Compass a voice question, get a spoken answer.
7. Close: "This used to mean a scheduled meeting with an advisor three weeks out. Now it's instant."
